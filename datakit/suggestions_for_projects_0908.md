# 三个数据产品「展现形式」升级建议（2026-09-08）

> 结论先行：三个产品的「分析资产」已经很强（血缘 lineage、复现清单 replication_manifest、
> 版本冻结 version_lock、manifest + alt_text、自包含 Kepler 地图），但「展示层」仍停留在
> 「给同行看的论文式交付」——一堆静态 PNG/PDF + Markdown，缺一个「给决策者 / 用户看的
> 产品式入口」。静态图是「死的」：不能 hover、不能下钻、不能切换分层、图与原始数据 / 代码
> 分离，所以「信服度」只能靠读者相信作者，而不是读者自己去戳数据。

---

## 一、现状总览

| 产品 | 现在的展示形态 | 已有「好底子」 | 缺什么 |
| --- | --- | --- | --- |
| project1 空间溢出 | 6 张静态图 + 1 张 Kepler 交互地图 + md 报告 | Kepler 自包含 HTML、lineage、replication_manifest | 只有地图交互，6 张报告图全死；结论散在多个 md |
| project2 生存模型 | 6 张静态图（KM/SHAP/ROC/系数森林/hexbin）+ md | SHAP、replication_manifest、预测口径 | 无交互地图、无可玩 demo，SHAP 是静态条形图 |
| project6 教学 | 13 张静态图 + md，定位「电子书/知乎/B站」 | 版本冻结、manifest、L0→L3 方法论主线 | 素材是「图」，还没组装成「可看/可玩的载体」 |

## 二、产品 1 · FDIC 空间溢出（研究 / 因果证据型）

**定位**：证明「网点关闭对周边同业存在空间溢出」，结论克制（关联非因果）。
**受众**：同行评审 + 决策者（银行 / 监管）。
**核心诉求**：让人「看得到空间效应如何随时间、距离演变」，并信服证据链完整。

| 优先级 | 形式 | 说明 |
| --- | --- | --- |
| ★ | **时空演变动画（王牌）** | Kepler 时间轴播放 1994–2025 关闭事件扩散，或逐年散点扩散动画——直接命中「空间溢出」，一张图证明「空间大数据」的价值 |
| ★ | **事件研究 + 距离衰减 交互图** | Plotly 化：τ 各期系数 hover 看数值 + CI；衰减曲线可切换「标准环 vs 合并环」（呼应 EXACT 坐标敏感性的克制） |
| ☆ | **Kepler 地图升级** | 在现有自包含地图上加 `time` 过滤器 + 图层开关（关闭事件 / H3 存款增长 / exposure 强度），点击网点看 30 年轨迹 |
| ☆ | **scrollytelling 数据故事** | 滚动叙事：结论 → 机制 → 证据 → 反例 → 限制，把「关联非因果」这个克制讲透 |
| — | **证据链下钻** | 图上点 → lineage / 来源产物；把「EXACT < 100% → <1 km 环失真」这类敏感性做成可展开项，不埋在 md 里 |

> **要点**：守住克制。展示层要反复强调「关联证据非严格因果」，这是本产品的可信度来源，不是减分项。

## 三、产品 2 · FDIC 生存模型（预测模型 / 可解释性产品型）

**定位**：回答「什么网点会先死」，是可复用的风险预测模型。
**受众**：分析师 + 风控 / 决策者。
**核心诉求**：让人相信模型准（性能）、理解为什么（可解释），最好能**上手试**。

| 优先级 | 形式 | 说明 |
| --- | --- | --- |
| ★ | **预测 demo** | Streamlit / 纯静态：输入网点特征（存款、银行脆弱性、地理分散度）→ 实时输出存活概率 + 该预测的 SHAP 分解。「产品感」的核心，比任何图都强 |
| ★ | **SHAP 交互图** | 用 `shap` 的 JS 版（force / waterfall 出 HTML），替代静态条形图，让读者自己拖拽看特征贡献 |
| ☆ | **KM + ROC 交互** | Plotly 版 KM（hover 显示 at-risk 数，图例切换脆弱性分组 / 类别 / 历史关闭率）；ROC hover 显示阈值对应的混淆矩阵 |
| ☆ | **模型「体检报告」单页** | AUC/C-index/Brier + 系数森林 + 残差 Moran's I 合成一页，醒目标注「相关≠因果」「AUC 仅同口径可比」 |

> **要点**：标注边界。预测模型最容易被误读为因果 / ROI 工具，展示层必须显式声明「风险预测，非因果；不承诺阈值与 ROI」。

## 四、产品 6 · 空间教学管线（方法论 / 教学传播型）

**定位**：传播空间大数据方法论（L0 H3 网格 → L1 权重 → L2 滞后 → L3 距离环）。
**受众**：学习者。
**核心诉求**：让学习者按阶梯「看懂 → 能跑 → 能改」，**可复现 > 好看**。

| 优先级 | 形式 | 说明 |
| --- | --- | --- |
| ★ | **Jupyter Book / Quarto 电子书** | 每章 = 一个 L 阶梯，图 + 代码块 + Binder 一键运行（已有 version_lock，可复现是天然卖点） |
| ★ | **可交互 Moran 散点** | 用户切换数据集 / 权重方案 → 实时看散点 + 拟合线 + I 值变化。这是「教学」最好的形式：**让学生动手改变量看结果**（直接演示「权重定义对结论敏感」） |
| ☆ | **「阶梯对比」交互图** | 全局对比图 Plotly 化，hover 看 4 数据集数值，直观展示 sz_bike 自相关强 / brightkite 稀疏错配 |
| ☆ | **L0→L3 演化动图** | 每个阶梯一个 30 秒动图（点 → 格 → 邻居 → 滞后 → 距离环的演化过程），替代静态图 |
| ☆ | **Binder / CI 一键复现** | 教学产品信服度 = 可复现，比图片重要得多；已有的 `version_lock.json` 直接显性化 |

> **要点**：可玩性。教学产品最忌堆静态图——学生看不懂逻辑链，必须给「可改参数、可重跑」的交互。

## 五、差异化主轴（一句话）

| 产品 | 主轴 | 最重要的一个升级 |
| --- | --- | --- |
| 1 空间溢出 | **证据链叙事** | 时空演变动画（证明空间效应） |
| 2 生存模型 | **可上手的产品 demo** | 预测 demo + SHAP 交互（摸得到模型） |
| 6 教学 | **可复现交互教材** | 可交互 Moran 散点 + 电子书（动手改参数） |

## 六、落地优先级建议（三产品统一视角）

1. **先做「共用的低成本高收益」**：Plotly 化（`fig.write_html()` 极小改动，全场收益）+ 一键复现（把已有的 replication_manifest / version_lock 显性化为可点徽章 / Binder）。
2. **再做各自的「王牌」**：产品 1 时空动画、产品 2 预测 demo、产品 6 可交互 Moran 散点。
3. **最后做「生态」**：产品 6 的 L0→L3 阶梯作门户，把三产品串成「一套方法，三个应用」。

> 每步都复用已有资产（lineage / manifest / version_lock / Kepler），不推倒重来。
