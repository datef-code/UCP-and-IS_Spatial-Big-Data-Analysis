### 1.2 该会话确认的长期结论

**叙事层（简历/对外）**
- **主语转换**是核心：`我处理了 1.58 GB` → `谁的决策因此变了`；`三个独立项目` → `一条决策链上的三个环节`。
- 四个项目 = 一条决策链，**不是四份作业**：
  project2 事前风险预测 → project1 事后影响评估 → project6 客户教育与信任 → datakit 交付底座。
- 建议把项目名 `UCP-and-IS` 改成业务名（如「连锁网点空间决策分析平台」）。
- 角色写法：不写"独立开发"，写 `产品设计 + 数据工程 + 空间计量（独立完成）`。
- 技术栈按领域分组（空间 / 计量ML / 工程），不要罗列 `pandas、numpy、matplotlib` 这类基础项。
- **数字一致性风险**：`estimate.json` 的 SLX `W_treat=0.008986 (p≈0.0013)` 与
  `08_conclude/output/conclusion.md` 的 `0.0073 (p=0.009)` 不一致，面试被追问会翻车 → 以 `estimate.json` 为准。

**业务/产品层（可直接复用的口径）**
- 产品定位：**卖引擎不卖结论**（源数据公开可商用 → 结论无法独占）。
- 产品边界三条（写进交付物，不承诺）：
  1. **不承诺 ROI**（成本参数缺失，量纲不成立）；
  2. **不做个体预测**（属另一产品）；
  3. **只报关联、不报因果**（前 τ 轻微为负 + 区域共同冲击）。
  → 「把"不能用"做成护栏页，是定价能力而非成本」。
- 结论强度分级 **A 准因果 / B 关联 / C 描述性** → 对应不同价格与用途；内生性过强时主动降级。
- 商业模式三级跳：**项目制咨询 → 标准化评估报告 → 指标订阅/API**；
  目标客群先咨询/研究机构（决策链短），再切连锁零售/餐饮/药店。
- **迁移成本模型**（用于报价与产品化）：
  展示层 1 周 / 工程层 1–2 周 / 空间层 1–2 周 / 识别层 2–4 周 / **数据层 3–6 周（最难）**。
- **售前 Go/No-Go 准入清单**（首周过滤不合格需求，六条）：
  稳定实体 ID、坐标可用率、网点级结果变量、时间跨度 ≥5 年、可定义外生事件、样本量。
- **诚实清单**：商业化文档里的市场规模/客单/人日**全是 `XX` 占位**，简历上不得编造。
  三个低成本补法：① 用"结构性判断"替代 TAM；② 补真实对照基线（朴素前后对比 vs 因果估计，
  展示方向相反或量级差 X 倍，是售前最有杀伤力的图）；③ 90 天内做一次真实 POC/用户测试。

**面试准备（三个必被追问点）**
1. 「TWFE 在 staggered DID 下有负权重偏误」→ 未用 Callaway–Sant'Anna；用**网点级事件研究 + 前 τ 检验**交叉验证，
   并**主动把结论降格为关联证据**。
2. 「存款下降为什么说是再配置」→ 网点级 `post` 为负 + 聚合层 SLX `W_treat` 为正 →
   本地被吸走、邻域补回，两个尺度方向相反。
3. 「26 分钟重跑算快吗」→ 不硬吹，讲瓶颈与手段（`usecols` 列裁剪、Parquet 中间层、
   cKDTree 粗筛规避 O(N²)），并主动说明已知短板（无增量缓存 / 无全链路 Parquet / 无调度）。

**三条"企业感"表述（可直接背）**
1. 「我卖的不是美国银行网点的结论，是一台跑过 282 万条记录、32 年数据验证的空间影响评估引擎
   —— 结论因数据公开而无法独占，所以我从一开始就按引擎而不是按报告来设计。」
2. 「我把"不能用"也做成了产品：护栏页、结论强度分级 A/B/C、售前准入清单。
   客户最容易的误用是拿它论证"关店能带来 X% 增长"，一次误用的损失远大于一单收入。」
3. 「迁移成本里最贵的不是算法，是数据体检 —— 主键稳定性、坐标精度、缺失机制。
   这三条无法从文档得知，只能实测，所以它既是成本，也是我的壁垒。」
