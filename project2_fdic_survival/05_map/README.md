# 05_map · ⑤ 映射（生存分析数据底座）

> 项目：[project2_fdic_survival](../README.md)　|　规范：`datakit/PROJECT_STRUCTURE.md` §2-⑤

## 本阶段做什么

回答「原始字段怎么变成分析字段」：长表 → **网点维度表**（风险集骨架）→ **空间网格**
→ **银行层共享脆弱性分层**，并给出字段血缘与映射后字段数据报告。

## 输入 / 输出

- **输入**：③ 的 `cleaned.parquet` + `config/mapping.yaml`
- **输出**（本阶段 `output/`）：

| 产物 | 内容 |
| --- | --- |
| `map.yaml` / `map.md` | 映射报告：操作明细、形状、生存口径分布、银行分层 |
| `lineage.csv` | 字段血缘：输出字段 ← 来源字段 / 表达式 / 映射方式 |
| `fields.csv` | 映射后字段数据报告（类型 / 非空 / 缺失率 / 唯一值 / 统计） |
| `mapped.csv` | 网点维度表（= 交付下游的过程数据） |
| `data/branch_panel.csv` | 网点维度表（每 `UNINUMBR` 一行） |
| `data/bank_fragility.csv` | 银行脆弱性分层（每 `CERT` 一行） |

## 实现

`05_map.py::run(project)`：pandas 按 `UNINUMBR` / `CERT` 聚合 + `dk.MappingScheme`
（`geocode` H3、`derive` 事件与截断标记），降级方案为 0.01° 网格。

## 本阶段口径要点（本次运行）

- 网点 **152,538**：关闭 80,695（52.90%）/ 仍存活 71,843（**右删失 47.10%**）；左截断 51.76%。
- 空间：`h3_r7`（≈1.22 km，与降级网格 0.01° ≈ 1.1 km 同尺度）；同格网点数 = `neighbor_count`（竞争强度）。
- 银行 **15,505**：L0 单网点 3,559 / L1 多网点高集中 5,918 / L2 多网点地理分散 6,028。
- **CERT 归属取首次观测值**：银行层脆弱性是基线属性，并购后不追溯重标，避免把事后结果倒灌进事前协变量
  （按末次 CERT 归属时银行数会收敛到 9,545，且测试 AUC 由 0.881 降到 0.812）。
