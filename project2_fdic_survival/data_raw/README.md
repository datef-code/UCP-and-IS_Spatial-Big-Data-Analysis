| 只读约束 | **任何脚本都不得写入本目录** | 规范 §1 |

## 字段口径要点（本项目只用其中 10 列）

| 字段 | 口径 |
| --- | --- |
| `UNINUMBR` | 跨年唯一网点号 —— **本项目追踪主键** |
| `BRNUM` | 银行内网点序号，跨年会重编号（实测：观测 ≥2 年的 146,396 个网点中 **52.19%** 首末年变化；CERT 同步变化 52.17%），**不可作跨年键** |
| `CERT` | 银行（机构）编号；并购后网点会改挂新 CERT（本项目按**首次观测**归属） |
| `YEAR` | 数据年份（1994–2025） |
| `SIMS_ESTABLISHED_DATE` | 网点设立（出生）日期；缺失 35.81% → 按左截断处理 |
| `SIMS_ACQUIRED_DATE` | 被并购 / 关闭（死亡）日期；缺失 66.36% = **右删失**，**禁止填充** |
| `DEPSUMBR` | 网点存款余额（美元）；无缺失、无负值（实测全期负值 0 条） |
| `SIMS_LATITUDE` / `SIMS_LONGITUDE` | 网点坐标；缺失 8.04%（清洗后置空越界值后为 4.19%） |
| `BKCLASS` | 银行类别（N / SM / NM / SB / SA …） |

> 完整字段等级与规则见 `../config/schema.yaml`；清洗口径见 `../config/clean_plan.yaml`。

## 可信度评估（规范 §9.3：覆盖范围 / 精度 / 缺失与已知偏差）

> 全部数字为**本地全量实测**（32 个年度文件、2,822,977 行）。与 `project1_fdic_spatial`
> 同源，可比对该项目 `data_raw/README.md` 的完整版。

### 覆盖范围

| 项 | 实测值 |
| --- | --- |
| 时间覆盖 | 1994–2025，32 年无缺年 |
| 结构覆盖 | 81 列 × 32 年完全一致，无列漂移 |
| 记录覆盖 | 2,822,977 行；`UNINUMBR` 非空后可追踪网点 152,538 个（其中观测 ≥2 年 146,396 个） |

### 精度

| 项 | 实测值 |
| --- | --- |
| 坐标越界（`|lat|>90` 或 `|lng|>180`） | 全期 **5 条**（2024 年 3 条、2025 年 2 条）→ ③ 阶段 `to_null` |
| 坐标落在 (0, 0) 空岛 | 全期 572 条（量级可忽略，但不被范围断言捕获） |
| `DEPSUMBR` 负值 | **0 条** |
| `SIMS_PROJECTION` 编码体系 | 1994–2022 用 `US_Rooftop`/`US_Streets`/`US_Zipcode`；2023–2025 改用 `EXACT`/`StreetAddress`。**词表不可跨年代比较** |

### 缺失与已知偏差（对生存分析尤其关键）

| 项 | 实测值 | 偏差性质 |
| --- | --- | --- |
| **`UNINUMBR` 缺失** | 120,261 行 = **4.26%**；**100% 集中在 1994–2010**，2011–2025 **零缺失** | **时间结构化缺失，非随机**。本项目的寿命追踪在早年系统性不可得 → **年龄/ duration 的分布对早年样本不具代表性**，左截断处理须谨慎 |
| `SIMS_LATITUDE` 缺失 | 226,932 行 = **8.04%**，其中 97.8% 落在 1994–2010；清洗后置空越界值后为 4.19% | 无坐标网点不进入 H3 网格 → `neighbor_count` 记 0，属**结构性缺失**而非随机 |
| `SIMS_ESTABLISHED_DATE` 缺失 | 35.81% | 出生年未知 → 按**左截断**处理，不填充 |
| `SIMS_ACQUIRED_DATE` 缺失 | 66.36%（2025 单年 43.64%） | 缺失 = **右删失**（仍存活），有语义，**禁止填充** |
| `BRNUM` / `CERT` 跨年不稳定 | BRNUM 52.19%、CERT 52.17% 首末年变化（两者同步：BRNUM 是银行内序号，CERT 一变必然重编） | 唯一 ≠ 稳定 → 只能以 `UNINUMBR` 追踪；`CERT` 按**首次观测**归属是口径选择，改按末次则 AUC 0.881 → 0.812 |

**结论**：SOD 作为权威监管数据可靠。本项目最大的可信度边界是**早年的时间结构化缺失**
（`UNINUMBR` 与坐标均在 2011 年前大量缺失），它同时影响「左截断」与「空间协变量」两块，
已分别写入 `08_conclude` 的已知限制。
