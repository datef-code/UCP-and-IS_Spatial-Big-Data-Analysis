引言：为什么要空间维度

如果只把数据当「一行行记录」，你会漏掉一件事：它们彼此之间有位置关系。

深圳单车的起终点挤在同一座城市，Brightkite 的签到散落全球——同样的「计数」， 在不同的空间结构里，含义完全不同。本教程用一条四步流水线把「位置关系」显式地算出来。

L0 · 把点装进 H3 六边形格

点太密、太乱，先离散化：把每个点映射到 Uber H3 的 R8 六边形（平均 0.737 km²）， 格内求和得到「格值」。这一步把「点云」变成「栅格」。

关键事实：四个数据集的格数从 2,661（sz_bike）到 302,580（gowalla） —— 规模差异 100 倍，是后面所有结论的地基。

📝 待补：H3 为什么用六边形（而非方格）；R8 分辨率怎么选。

L1 · 定义「谁是邻居」

空间权重矩阵 W 是空间分析里最主观、最影响结论的一步： Queen 邻接（共享边）还是 KNN（最近 k 个）？行标准化还是二值？

一句话记住：「邻居」是人为定义，不是客观事实。 换一种定义，Moran's I 会跟着变。

📝 待补：W 的行标准化推导；孤岛格（无邻居）怎么处理。

L2 · 空间滞后与 Moran's I

空间滞后 Wx = 邻居的均值。把格值画在横轴、滞后画在纵轴， 散点拟合线的斜率就是 Moran's I。

亲手切换数据集 / 权重 / 格值尺度，看 I 怎么变（本教程最重要的一课）。

📝 待补：I 的显著性（置换检验）与「I 依赖变量尺度」的讨论。

L3 · 邻居换成距离环

「谁是邻居」还可以用距离回答：以热点格为圆心画环（0–1 / 1–3 / 3–5 / 5–10 km）， 看效应怎么随距离衰减。

关键事实：计数口径会随环面积增大而虚高， 必须除以环面积看密度，才看得到真实的「随距离衰减」。

📝 待补：距离环 vs 权重的取舍；边界效应。

结论与限制

  • 结论 1：空间权重矩阵的定义对结论敏感——跨研究比较 I 必须同尺度、同权重、同网格。
  • 结论 2：看到很低的 I，先问「是不是数据本来就稀」（孤岛格多），别急着说没有空间效应。
  • 限制：所有成本参数（R8 / 环宽 / 抽样日）都是合成参数，非真实业务口径。
