## 〇、一页纸摘要（管理层只看这段）

我们把"空间大数据怎么结构化"这件事，做成了一套**能自己动手、能一页页读完、能复现出同样数字**的

覆盖 **4 个数据集、1,991 万条记录、60.4 万个 H3 网格**。

核心教学主张（一句话）：

> **「邻居」怎么定义，决定你能看到什么结论。**
> 同一个数据集换一种空间权重矩阵，Moran's I 会从 **0.71 变成 0.01**——
> 这不是缺陷，而是本教程**最想教的一件事**。

实测证据（四数据集对比，同尺度、同权重、同网格）：

| 数据集 | 点数 | H3 格数 | Moran's I | 空间滞后相关性 |

## 一、产品概述

### 1.1 它是什么

`project6_spatial_teaching` 是一套**空间结构化教学产品**：以 4 个风格迥异的真实数据集为例，
把"点数据 → 空间结构化 → 空间统计"的全过程，拆成**四阶认知阶梯**：

| 层级 | 做什么 | 回答什么 |
| --- | --- | --- |
| **L0** | 点 → H3 六边形网格聚合 | 这一格"有多少"？（格值分布 / ECDF） |
| **L1** | 定义邻接 → 空间权重矩阵 W | 谁是"邻居"？有多少邻居？有多少**孤岛**？ |
| **L2** | 计算空间滞后 `W·y` → Moran's I | 相似的值是聚在一起还是散开的？ |
| **L3** | 以热点为圆心画距离环（0–1 / 1–3 / 3–5 / 5–10 km） | 影响**传多远、衰减多快**？ |

教材不是讲概念，而是**每一步都给出真实数据集的真实数字**，读者可以自己拨开关验证。

### 1.2 为什么做

- 空间分析的学习曲线陡，卡点高度集中在两处：**权重矩阵怎么定**、**尺度怎么选**。
  官方文档与教科书普遍只给公式，不给"换个设定结论会变成什么样"的对照。
- 团队内部已有 ③④⑤ 阶段（清洗 / 校验 / 映射）跑通的真实产出，
  **直接复用**即可，不需要新建模——**这是低成本高杠杆的内容资产**。
- 对外看，空间大数据是稀缺能力标签，但缺少**可被外部验证的载体**；
  一套"clone 下来就能重跑出同样数字"的教材，比任何 PPT 都更有说服力。

> **kill switch（立项时就写死的止损）**：若 ③④⑤ 未做，本方向会退化为"官方文档翻译"，
> 那时应直接砍掉。目前 ③④⑤ 已实际跑通，**前置条件成立**。

### 1.3 产品形态（三层交付）

## 二、核心功能与亮点

### 2.1 功能一：把"权重矩阵决定结论"做成能亲手拨的开关（**最大差异化点**）

教科书只会告诉你 Moran's I 的公式。我们把它做成可交互实验：

- `weight_lab.html`：**切数据集看 L1 详情** + 六边形邻接 SVG + 平均邻居数 × Moran's I 气泡散点 + 孤岛率条。
  一眼看出 `sz_bike` 平均 5.07 个邻居（I=0.71）与 `snap_brightkite` 平均 2.01 个邻居（I=0.013）的差距。
- `moran_explorer.html`：I 对比条 + **四象限解读**（高-高 / 低-低 / 高-低 / 低-高）+ 公式。
- `ring_decay.html`：**同一份数据，一键切"环内求和 / 溢出密度 / 归一化"三种口径，结论方向会变**——
  这是全书最有冲击力的一个页面。

> 一句话：**别人教"Moran's I 是什么"，我们教"你凭什么相信你算出来的那个 I"。**

### 2.2 功能二：15 页电子书（**不是几张孤立图的"图集"**）

| 设计点 | 解决什么 |
| --- | --- |
| 左侧**常驻分组目录**（入门 / L0–L3 / 综合 / 实践 / 收尾）+ 当前页高亮 | 新人不知道从哪开始、也不知道读到哪 |
| 每章**「你将学到」+ 章尾「下一步」** | 每页有明确目标与出口，不会迷路 |
| **关键词搜索**（按 `/` 聚焦） | 回查概念不用一页页翻 |
| **进度条 + 页码 + localStorage 记忆** | 分几次读完也能接上 |
| **深色模式**（随系统 + 手动切） | 投影用深色、自己看用浅色 |
| 每章**内嵌对应交互件**（iframe） | "只读不做"学不会，翻到哪章就动手哪章 |
| **常见误区 7 条 + 迁移清单 + 术语表** | 把散落各章的坑收拢，并给出"用到自己数据上"的检查清单 |

### 2.3 功能三：跨数据集对照（**用差异教方法，而不是用定义教方法**）

- `ladder_compare.html`：8 个指标下拉切换 + 三层对数折线 + **完整数字表**，
  四个数据集在 L0–L3 每一层的差异一目了然。
- `method_atlas.html`：**方法卡可展开**（输入 / 输出 / 参数 / 为什么 / 坑 / 代码位置），按 L0–L3 分层筛选——
  从"学会这个操作"升级到"知道这条管线上每个方法为什么在这儿"。

### 2.4 功能四：可复现被做成产品的一部分（**教学产品的信服度来源**）

- `index.html` 把四个数据集的 `version_lock.json`（**冻结时间 / 行数 / 库版本 / 合成参数**）做成表格。
- **I 与管线逐位对齐**：页面用 Queen + 原始格值算出的 I，与 `05_map` 的 `ladder_report.json`
  **完全一致**（fdic 0.1331 / sz_bike 0.7077 / brightkite 0.0132 / gowalla 0.5090）。
  这一点是**标定出来的，不是碰巧**——曾用 log1p 得到另一组数值、与管线不符，
  于是改为把"**尺度**"本身做成一个教学点。
- **权重在服务端算好**：30 万格 × 3 方案 × 2 尺度 × 4 数据集全塞进 HTML 会上百 MB，
  客户端也扛不住矩阵运算 → 权重与滞后由 h3 + libpysal 在服务端算（与 ⑤ 映射同一套算法），
  前端只切换与重绘，**每个 I 都可复现，不是客户端近似**。

### 2.5 功能五：缺数据显式降级 + 把踩过的坑变成教材

- 格级 CSV 受仓库 `.gitignore` 约束**不入库**（重跑 ⑤ 又要 30 GB 原始数据）→
  定了一条硬口径：**CSV 在则出可交互散点/动图；不在则降级为上游真实静态图 + 显式披露**。
  展示阶段 `blocking: false`，**绝不因为缺 CSV 整段失败，也绝不为"好看"画一张编出来的图**。
- **踩过的坑都收进了教材**，例如：
  - **KNN 爆内存**：不能算 n×n 距离矩阵（30 万格直接爆），改用 3D 直角坐标 + KD-tree
    （弦距与大圆距离单调同序，最近邻排序一致，但快几个数量级）；
  - **孤岛格必须纳入权重矩阵**：`libpysal.weights.W` 必须覆盖全部格（含孤岛），
    否则 `w.n < n` 会让滞后维度对不上；
  - **几何范围断言漏网**：动图顺带发现 `sz_bike` 有 **(0,0) 空岛** 与
    **lat=47.66 / lon=132.54 的飞点**——两者都"合法"（在经纬度范围内），
    所以 ④ 的范围断言查不出来。**根治需要在 schema 里加业务范围的合理性规则**，
    这本身已成为电子书「常见误区 ⑦」。

### 4.2 核心结果（可直接引用）

**① 空间聚集强度：差 50 倍以上**

| 数据集 | Moran's I | 滞后相关性 | 平均邻居数 | 孤岛格 |
| --- | --- | --- | --- | --- |
| `sz_bike` | **0.7077** | 0.8581 | 5.07 | 121 |
| `snap_gowalla` | 0.5090 | 0.7246 | 2.40 | 66,069 |
| `fdic` | 0.1331 | 0.2163 | 1.41 | 19,786 |
| `snap_brightkite` | **0.0132** | 0.0266 | 2.01 | 67,189 |

- **最强 `sz_bike`**：同城密集点位，邻接格彼此可观测 → I 高达 0.71。
- **最弱 `snap_brightkite`**：点位稀疏且全球分散，H3 R8 近邻格常为空 →
  **权重矩阵的定义对结论极其敏感**（孤岛 67,189 个，占格数近 3 成）。

**② 距离衰减：4 个数据集全部成立**

以 `fdic` 为例，溢出密度随环距递减（7.62 → 2.13 → 1.72 → 1.64）；
`sz_bike` 从 24,612 → 6,867 单调衰减；`snap_gowalla` 从 4,024 → 124，衰减最陡（约 33 倍）。

**③ 一句话结论**

> 空间权重矩阵的定义（分辨率、邻接阶数、是否行标准化）**直接改变结论**：
> 同一个数据集换一种 W，Moran's I 会变——**这是本教程的核心观点，而非缺陷**。

2. **成本参数为合成参数**：`h3_res=8`、`hot_top_n=100`、距离环 0–1/1–3/3–5/5–10 km、

6. **数据质量遗留**：`sz_bike` 的 (0,0) 空岛与飞点已按 bbox 裁切（动图副标题写明剔除多少格），
