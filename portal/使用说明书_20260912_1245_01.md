> **产品**：网点决策台（Spatial Decision Platform）
> **文件**：`portal/index.html` + `portal/serve.py`（含 `ingest.py` / `refit.py`）
> **版本**：v2.4　|　**日期**：2026-09-12　|　**文档**：`使用说明书_20260912_1245_01.md`
> **适用对象**：第一次打开产品的人、要拿它给客户做评估的人、要接入自己数据的人

## 0. 一页速览

| 问题 | 答案 |
|---|---|
| 这是什么 | 一个**空间决策证据工作台**：把「关一家门店，周边会发生什么」变成能被质询的答案 |
| 和普通看板的区别 | 它卖的不是结论数字，而是**判断结论能不能用**的方法——每条结果都自带可信度等级、使用边界、证据来源 |
| 怎么打开 | 双击 `index.html`（离线可用）；要接自己的数据则双击 `portal/start.bat` 起本地服务 |
| 主流程 | 数据接入 → 准入体检 → 冲击评估 → 风险归因 → 口径实验室 → 评估报告（六步） |
| 数据从哪来 | ① 内置示例 ② 你上传的 CSV ③ 本机路径（如 `data_raw/fdic/*.csv`）④ 用你的数据现场重估系数 |
| 数据去哪了 | 只存在浏览器 `localStorage`，不上传服务器；上传的文件在响应结束后立即删除 |
| 最短上手 | 工作台 → 页面底部「载入这个示例」→ 按提示一步步点到底 → 报告页「生成 / 刷新报告」 |

## 1. 启动与访问

### 1.1 形态 A · 静态（零依赖，默认可用）

**双击 `portal/index.html`** 即可。离线可开、无需安装、无任何 CDN 依赖（图表为手写 SVG）。

| 模块 | 形态 A 是否可用 |
|---|---|
| ① 数据准入体检（手填问卷） | ✅ |
| ② 冲击评估 | ✅ |
| ③ 风险归因 | ✅ |
| ④ 口径实验室 | ✅ |
| ⑤ 评估报告 | ✅ |
| **数据接入（上传 / 本机路径 / 重估）** | ❌ 需本地服务 |

### 1.2 形态 B · 本地服务（解锁数据接入与重估）

**Windows**：双击 `portal/start.bat`。
脚本会自动完成四件事：找 Python（优先仓库自带的 `datakit/.venv`）→ 检查依赖 → **挑一个没被占用的端口**（8765 起）→ 起服务并打开浏览器。

**Git Bash / macOS / Linux**：

```bash
bash portal/start.sh
```

**手动等价命令**：

```powershell
cd <仓库根>
datakit/.venv/Scripts/python.exe portal/serve.py            # 默认 http://127.0.0.1:8765
datakit/.venv/Scripts/python.exe portal/serve.py --port 9000 --no-browser
```

进入产品后，打开「数据接入」页，右上角会显示 **`服务可用（接入 + 重估）`**，说明解锁成功。

### 1.3 启动故障排查

| 现象 | 原因 / 处理 |
|---|---|
| `[x] Python not found` | 装 Python 3.11+，或恢复仓库自带的 `datakit/.venv`（见 `datakit/README.md`） |
| `[x] Missing dependencies` | 必须用仓库自带的虚拟环境启动，不要用系统 Python |
| 可选依赖缺失提示 | 缺 `statsmodels / libpysal / esda / spreg` → 「重估」与「空间口径」降级，其余功能正常 |
| 端口被占用 | 脚本会自动换端口；也可显式 `--port 9001` |
| 界面中文乱码 | 两个脚本已设 `PYTHONUTF8=1`；手动启动时请自行设置该环境变量 |
| 数据接入页显示「未启动本地服务」 | 服务没起或端口不对；页面顶部会给出具体错误 |

> 说明：`start.bat` 刻意保持**纯 ASCII**。`cmd.exe` 用 OEM 代码页（简体中文为 GBK）解析批处理文件，
> 文件里的中文会吞掉下一行前缀导致报错；中文文案一律由 Python 打印。

## 3. 三条使用路径

### 路径 A · 只想看看它能做什么（5 分钟）

1. 打开 **工作台**
2. 滚到页面底部 **「一键载入示例项目」**，点其中一个「载入这个示例」
3. 顶部会出现 **「建议下一步」** 卡，跟着它点：准入体检 → 冲击评估 → 风险归因 → 评估报告
4. 每个结果页都要看 **「使用边界」**——那几行是这个产品真正的价值所在

### 路径 B · 要用我自己的数据（推荐）

1. 双击 **`portal/start.bat`** 起服务
2. 进入 **数据接入**：上传多份文件（可多选 / 选整个文件夹），或填**本机路径**
3. 核对 **字段映射**（自动推断可改，改完点「按当前映射重算」；可存成模板复用）
4. 点 **「开始重估」** → 看**能力判定**（impact / spatial / risk 各是 ✓ 还是 ✗）→ 点 **「载入为当前数据层」**
5. 之后四个模块就按**你自己的系数**工作；工作台顶部会出现黄条，可一键「恢复仓库产物」

### 路径 C · 要交付给别人

1. 走完 数据接入 → 准入体检 → 各分析模块
2. 到 **评估报告** 点「生成 / 刷新报告」
3. 用「打印 / 导出 PDF」交付报告正文（打印时自动隐藏导航与表单），或「下载 .md」给协作方
4. 「下载结果 JSON」交给下游程序；「工作台 → 导出项目 JSON」用于**存档与下次恢复输入**

## 4. 六步流程逐页说明

### 4.0 数据接入（需本地服务）

> 目的：把「很多份文件、字段还不一样」的数据变成一份可用的数据集，并可选地用它重估系数。

**① 数据来源**（三种接法）

| 方式 | 操作 | 适用 |
|---|---|---|
| 多选文件 | 点「Choose File」多选 | 小数据，几 MB～几十 MB |
| 选择文件夹 | 点「选择文件夹」 | 一次拖入整个目录 |
| **本机路径** | 填路径或通配符，分号分隔；可设「文件上限」 | 大数据（不受 512 MB 上传上限约束，且不复制数据） |

路径示例：`data_raw/fdic/*.csv`　`data_raw/snap_brightkite`　`data_raw/sz_bike/bike_2020010*.csv`

**② 数据集** —— 显示：合并后行数 × 列数、形态徽章、每个文件的行/列/大小/状态；
若各文件列不一致，会列出**只在部分文件出现的列**（已按列名并集拼接，缺处留空）。

**③ 字段映射** —— 7 个角色，**靠取值分布自动推断，不靠列名**：

| 角色 | 推断依据 |
|---|---|
| 实体 ID | 高基数，且在「期」上有重复（行级代理键会被降权） |
| 时间（期） | 整数且值域落在 1600–2200，多期再加权 |
| 事件时间 | 日期型列（如 ISO 时间戳） |
| 纬度 / 经度 | 值域合法 + 成对出现；带坐标语义名时放宽跨度要求 |
| 结果变量 | 数值、有方差；过半为 0 的粗粒度汇总会被降权 |
| 分组 / 行业 | 低基数类别列 |

改完映射点 **「按当前映射重算」**；「存为映射模板」后可给同结构的数据一键套用。

**④ 体检结果** —— 按形态路由到不同规则集：

| 形态 | 何时判定 |
|---|---|
| `panel` | 有实体 + 期，且 (实体,期) 唯一 |
| `repeated_panel` | 同上但有重复 → 提示先聚合或换主键 |
| `event_log` | 实体 + 事件时间（无逐年期） |
| `cross_section` | 有坐标、无实体-期 |
| `time_series` | 只有时间列 |
| `network` | 无时间无坐标、但有 ≥2 个高基数 ID 列（疑似边表） |
| `unknown` | 认不出来 → **明确要求人工指定，不猜** |

每条体检给出 `OK / WARN / DANGER` 三级 + 说明 + 建议动作。

**⑤ 用这份数据重估系数**（可选）—— 4 个可选列：

| 选项 | 用途 |
|---|---|
| 处理年 | 实体开始受处理的年份列（DID 的 post 起点） |
| 处理标记 | 0/1 列（替代处理年） |
| 暴露强度 | 数值列；**不填则退化为二元处理**（强度 ≡ 1） |
| 退出目标 | 0/1 列，用于 cloglog 风险模型 |

不填任何处理定义时：若数据有事件时间列，自动以「**首次事件年**」为处理起点。
点「开始重估」后给出**能力判定**（能做就 ✓，做不了就 ✗ 并说明原因），再点「载入为当前数据层」。

---

### 4.1 数据准入体检

> 目的：**先判断能不能做、能做到什么等级**，避免把不合格需求做成一份好看但没用的报告。

**怎么做**：回答 7 个问题；起了本地服务的话，也可以上传 CSV 让它**自动预填**其中几项。
另有「填入示例答案」「清空」两个快捷按钮。

| # | 问题 | 阈值 |
|---|---|---|
| ① | 是否有可跨年追踪的稳定实体 ID | 一票否决级 |
| ② | 实体匹配准确率 | ≥ 90% |
| ③ | 坐标缺失率 | ≤ 20%（超过 → 一票否决） |
| ④ | 结果变量层级 | 必须「门店级连续指标」 |
| ⑤ | 时间跨度 | ≥ 5 年 |
| ⑥ | 是否存在明确、可观测的退出/进入时点 | — |
| ⑦ | 事件是自主决策还是外生冲击 | 决定结论上限 |

**你会得到**：Go / No-Go 判定、可行性得分、**结论强度上限 A/B/C**、预计工期区间（周）、
**阻断项**（一票否决的具体原因）、**缺口清单**（扣分但可通过补数解决）。

> ⑦ 是决定性的：**外生冲击**（竞对破产清算、政策强制关停、租约集中到期）才近似满足平行趋势，
> 上限可到 A/B；**自主关店**与商圈衰退高度相关，内生性显著更强，上限直接压到 C。

---

### 4.2 冲击评估

> 回答「影响多大、传多远、第几年最深」。

**输入**：两个滑杆——**暴露强度**（0–5）与**事件年份**（1994–2025）；另有 4 个预设强度一键填入。

**你会看到**：
- **点估计卡**：你输入强度处的效应、τ=0 效应、τ=+4 效应、事件前最大 |t|、**均值处边际效应**
- **强度—效应曲线**：带 95% 区间，**绿色阴影为观测支撑域**
- **逐年事件研究曲线**：带置信带
- **本地 / 邻域分解**：两者方向相反说明是"存款再配置"而非区域净增
- **动态告警**：输入强度**落在外推区**（低于实测支撑域下界）时弹**红色**告警并声明"该点未被观测，
  结果不可直接引用"；事件年份落在坐标精度较低的年代时弹**黄色**告警
- **使用边界（随结果常驻的 3 条）**：不得用于 ROI 测算或干预阈值决策、不得对外作因果表述、
  不得跨年代直接比较坐标精度

**必须知道的引用方式**：`β_post` 是**暴露强度 = 0 处的外推**，而处理组强度恒 > 0、该点从未被观测
→ **不能单独引用**，应以「均值处边际效应」为准。

---

### 4.3 风险归因

> 回答「哪些门店最可能出事、主要由什么决定」。**它是归因，不是预测。**

**输入**：6 个滑块（所属银行历史关闭率、存款规模、同格网点数、网点年龄、纬度、经度）
+ 3 个下拉（年份 1994–2015、银行类别、脆弱性分层）+ 3 个预设样本。

**适用域守门**：年份超出 1994–2015 或银行类别系数已退化的，**直接拒绝打分并解释原因**——
这是护栏，不是 bug。

**你会看到**：
- 归因卡：线性预测器 η → 经 cloglog 链接得到风险概率
- 因子贡献表：每个特征的系数 × 输入值
- **全特征值 vs 剔除泄漏特征后的保守值**（两者必须一起看，保守值只用于相对排序）
- 模型体检条：随机划分 AUC、时序外推 AUC、测试集事件率 ≠ 真实事件率
- 残差 Moran's I：显著为正说明本地市场因素未进模型

---

### 4.4 口径实验室

> 「邻居」是人为定义，不是客观事实。

切换 4 个数据集，看同一方法在不同口径下的差异（Moran's I 从 0.0132 到 0.7077）。
**合规提示**：SNAP 两个数据集**禁商用**，商用版只剩 `fdic` 与 `sz_bike`。

### 4.5 评估报告

点「生成 / 刷新报告」后，报告包含：结论强度、使用边界、**禁止用途**、完整**数据血缘**、

导出方式：

| 按钮 | 产出 | 用途 |

## 5. 内置样例详解

### 5.1 工作台的两个示例项目（「载入这个示例」）

两个示例都是**演示用构造数据**，但参数取自本项目真实分布，且**期望结果由引擎实测锁定**（有回归单测保证）。

| 项目 | **示例 A · 咨询机构的连锁零售客户** | **示例 B · 银行并购整合** |
|---|---|---|
| 名称 | 某连锁便利店 · 竞对退出影响评估 | 某银行 · 并购重叠网点取舍评估 |
| 客户 | 某咨询机构（终客户：连锁便利店） | 某城市商业银行 |
| 行业 | 连锁零售 / 便利店 | 银行 / 网点网络规划 |
| 决策问题 | 竞对破产清算后，我方 3 km 内门店的销售额影响有多大、传多远 | 并购后重叠网点如何取舍、关掉 A 点会不会伤到 3 km 外的自家 B 点 |
| ①稳定实体 ID | ✅ 是 | ✅ 是 |
| ②匹配准确率 | 94% | 72% ↓ |
| ③坐标缺失率 | 3% | **28% ↓（超 20% 阈值）** |
| ④结果变量层级 | **门店级连续指标** | **仅公司级汇总 ↓** |
| ⑤时间跨度 | 10 年 | 4 年 ↓ |
| ⑥事件可观测 | ✅ 是 | ✅ 是 |
| ⑦外生性 | **外生冲击**（竞对破产清算） | **自主决策**（并购整合） |
| 冲击输入 | 强度 1.2、事件年 2018 | 强度 1.0、事件年 2012 |
| 风险输入 | 年龄 25 / 存款 39,360 / 同格 5 / 38.9,-86.22 / 关闭率 0.25 / 2012 / N / L0_单网点 | 年龄 40 / 存款 120,000 / 同格 12 / 39.1,-94.6 / 关闭率 0.5 / 2009 / NM / L2_多网点地理分散 |
| 口径数据集 | fdic | fdic |

**引擎实测的预期结果**

| 结果 | 示例 A | 示例 B |
|---|---|---|
| 一票否决（hardFail） | 否 | **是** |
| 结论强度上限 | **B** | 无（被阻断） |
| 可行性得分 | 100% | 38% |
| 预计工期 | 8–15 周 | 10–20 周 |
| 阻断项 | 0 条 | **2 条** |
| 缺口 | 0 条 | 5 条 |

**示例 B 的 2 条阻断项**（这就是产品想教你的东西）：
1. `坐标缺失率 > 20% → 空间口径不可用`
2. `结果变量非门店级 → 无法构造门店级 outcome，DID 与事件研究均不成立`

> 教学意图：**示例 A 演示"一个能做的项目长什么样"**（干净的数据 + 外生事件 → 上限 B）；
> **示例 B 演示"产品会劝你别硬做"**（只有公司级指标 + 坐标缺失 28% + 内生事件 → 一票否决，
> 产品建议先去补数，而不是把不合格的数据做成一份好看的报告）。

### 5.2 冲击评估的 4 档暴露强度预设

强度定义：`treat_strength = log1p(5 km 内同业关闭事件数)`。

| 预设 | 强度值 | 约等于 |
|---|---|---|
| 低暴露 | 0.69 | 约 1 起同业关闭 |
| 中暴露 | 1.61 | 约 4 起 |
| 高暴露 | 2.40 | 约 10 起 |
| 极高暴露 | 3.09 | 约 21 起 |

> 真实数据的处置组强度实测范围是 `[0.1, 13.7]`（网点级均值 0.685、中位 0.5、148 个离散取值），

## 6. 结论强度 A / B / C 是怎么判出来的

**它不是手选选项，而是由引擎按真实产物自动判定**，并且工作台、冲击页、报告**三处用同一个评级器**（避免自相矛盾）。

判定规则（按顺序）：

1. **起点由外生性决定**：外生冲击 → `A`；自主决策 → `C`；未判定 → `B`
2. **事件前 τ 的 |t| ≥ 1.96**（平行趋势不理想）→ **降一级**
3. **前趋势量级比 `|τ=−2| / |τ=0| ≥ 0.5`** → **直接判 C**（触及"量级接近"止损条件）
4. 另外如实**列出但不额外降级**的事实：合并环敏感性未验证、无时序外推验证、未加 bootstrap CI

**含义**：

| 等级 | 名称 | 可以怎么用 |
|---|---|---|
| **A** | 强 | 可主张准因果（本项目当前拿不到） |
| **B** | 关联 | 可作关联性/机制解释，**不得对外作因果表述** |
| **C** | 描述性 | 只能描述与情景分析，不得用于决策阈值 |

## 8. 术语表

| 术语 | 解释 |
|---|---|
| **暴露强度** | 门店被"事件"波及的程度；本项目定义为 `log1p(5 km 内同业关闭事件数)` |
| **观测支撑域** | 模型只在实测到的强度范围内可信；低于下界即为外推 |
| **均值处边际效应** | 不引用强度 = 0 的外推点，改在实测均值处报效应 |
| **止损条件** | 写死在评级器里的红线，命中即自动降级或阻断 |
| **平行趋势** | 事件前处理组与对照组走势是否已经不同 |
| **目标泄漏** | 特征里混入未来信息（如用全期关闭率回填每一年）→ 指标虚高 |
| **口径** | 人为设定的定义（距离环 / 权重 / 栅格尺度） |
| **cloglog** | 一种离散时间生存模型的链接函数 `h = 1 − exp(−exp(η))` |
| **Moran's I** | 空间自相关指标，衡量"相邻格子是否相似" |
| **形态（Shape）** | 数据的结构类型：panel / event_log / cross_section / network … |

## 9. 常见问题

完整版见产品内「**帮助**」页（9 条可折叠 FAQ），这里只列最常被问的：

**Q：我的数据是多份文件、字段还不一样，能直接用吗？**
能。数据接入会按**列名并集**纵向拼接多份文件，缺列留空并登记；字段角色靠在**取值分布**推断，
不靠列名，推断结果可以人工覆盖并存成模板。

**Q：数据会上传到服务器吗？**
不会离开本机。服务只监听 `127.0.0.1`；上传的文件在**响应结束后立即整目录删除**，不持久化。
大数据建议用「本机路径」模式，连复制都不会发生。

**Q：为什么某个模块显示 ✗？**
能力判定是数据条件的函数，不是开关。单一年份 → 没有时间维，算不了 DID；
没有二元退出列 → 拟合不了 cloglog；没有经纬度 → 跳过空间部分。产品会明说原因，不硬套系数。

**Q：为什么一直强调"不能预测未来"？**
风险模型用随机划分且存在时序泄漏；剔除泄漏后时序外推 AUC ≈ 0.53（接近随机）。
所以它被定位成**归因**（解释历史、做情景分析），这是模型的真实状态，不是免责话术。

## 10. 已知边界（刻意不做的事）

1. **静态优先，无多租户**：不做用户系统、计费、持久化客户数据（后者反而是合规优势）
2. **商业数字为占位**：TAM/SAM/SOM、客单价一律标注「待填」，不臆测
3. **风险模型不可用于预测未来**，模块已改名为「归因」
4. **现场重估的覆盖范围有限**：空间样本是**实体级均值截面**（非格级）；
   不做距离环敏感性、不做时序外推验证——产物里如实写 `false`，评级器据此降级，不假装跑过；
   特征数上限 12，且不做共线性诊断
5. **泛化层不做跨文件实体对齐**：同名不同实体仍视为两个实体，需人工先清洗
6. **上游遗留**：`project1/08_conclude/output/technical_report.md` 的 SLX `W_treat` 排版值与
   `estimate.json` 不一致，本产品全程以 `estimate.json` 为准
7. **未做视觉验收的部分**：`07_visualize` / `09_interactive` 的图上产物不在对拍范围内
