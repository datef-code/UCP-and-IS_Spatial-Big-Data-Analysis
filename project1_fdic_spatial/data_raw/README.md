## 字段口径要点

- `UNINUMBR`：跨年唯一网点号 —— **本项目唯一追踪主键**（required）。
- `BRNUM`：银行内网点序号，跨年会重编号，**不可作跨年键**（ignore）。
- `CERT`：银行（机构）编号。
- `DEPSUMBR`：网点存款余额（美元）；结果变量来源。
- `SIMS_ESTABLISHED_DATE` / `SIMS_ACQUIRED_DATE`：设立 / 被并购日期；后者缺失 = 仍存活（右删失，禁止填充）。
- `SIMS_LATITUDE` / `SIMS_LONGITUDE`：网点坐标；`SIMS_PROJECTION` 为地理编码方式（见下「可信度评估」）。
- `BKCLASS`：银行类别（同业判定）；`MSABR` / `METROBR` / `CSABR` / `CBSA_DIV_NAMB`：都会区与联合统计区口径。
  **实测：1994–2025 全部 32 个年度文件均不含 `CBSA_METRO` 字段**，都会区只能用 `MSABR` + `METROBR` 构造。

跨年列结构一致性由 `01_discover/output/catalog.yaml` 的 `column_drift` 复核（当前全部一致）。
完整字段画像见 `02_profile/output/fields.csv`。

## 可信度评估（规范 §9.3：覆盖范围 / 精度 / 缺失与已知偏差）

> 全部数字为**本地全量实测**（32 个年度文件、2,822,977 行），非估计值。

### 覆盖范围

| 项 | 实测值 |
| --- | --- |
| 时间覆盖 | 1994–2025，32 年无缺年 |
| 结构覆盖 | 81 列 × 32 年完全一致，无列漂移 |
| 记录覆盖 | 2,822,977 行；`UNINUMBR` 非空后可追踪网点 152,538 个 |
| 地理覆盖 | 全美 + 在美外国银行分行；仅总行无分支的机构豁免申报（官方口径） |

### 精度（坐标与主键）

| 项 | 实测值 | 对结论的影响 |
| --- | --- | --- |
| `SIMS_PROJECTION` 编码体系 | **1994–2022 用 `US_Rooftop`/`US_Streets`/`US_Zipcode`/`0`/`100`；2023–2025 改用 `EXACT`/`StreetAddress`/`PointAddress`/`Postal`** | 词表不可跨年代直接比较，禁止用单一「EXACT 占比」衡量全期精度 |
| 2023–2025 屋顶级（EXACT） | **85.98%**（198,260/230,594） | 近三年坐标精度高 |
| 1994–2022 屋顶级（US_Rooftop） | **16.37%**；街道级 US_Streets 31.57%；邮编级 US_Zipcode 4.97% | **早年多为插值坐标 → 早年距离环误差显著大于近年** |
| 坐标越界（`|lat|>90` 或 `|lng|>180`） | 全期 **5 条**（2024 年 3 条、2025 年 2 条） | ③ 阶段已 `to_null`，可忽略 |
| 坐标落在 (0, 0) 空岛 | 全期 **572 条** | 未被范围断言捕获，量级可忽略但应知悉 |
| `DEPSUMBR` 负值 | **0 条** | 无异常 |

### 缺失与已知偏差

| 项 | 实测值 | 偏差性质 |
| --- | --- | --- |
| `UNINUMBR` 缺失 | 120,261 行 = **4.26%**；**100% 集中在 1994–2010**，2011–2025 **零缺失** | **时间结构化缺失，非随机**。③ 清洗删除的 4.26% 全部来自此处 → 早年样本系统性不可追踪，事件研究早期年份代表性弱 |
| `SIMS_LATITUDE` 缺失 | 226,932 行 = **8.04%**；其中 97.8% 落在 1994–2010 | 同上：早年空间可用性差于近年 |
| `SIMS_ACQUIRED_DATE` 缺失 | 全期 66.36%（2025 单年为 43.64%） | 缺失 = 右删失（仍存活），**有语义，禁止填充** |
| **`SIMS_ACQUIRED_DATE` 的年份上限** | 解析出的 `acq_year` 只落在 **1970–2015**（27,018 起关闭事件全部 ≤2015），**2016–2025 年没有任何事件** | **口径边界**：本项目的「处理」只存在于 ≤2015 的年份；2016–2025 的面板年只能当「事后追踪期」。任何把 post 期划到 2016 年以后的设定都没有事件支撑 |
| `BRNUM` 跨年不稳定 | 观测 ≥2 年的 146,396 个网点中 **52.19%** 首末年 BRNUM 变化；CERT 变化 52.17%（同步） | 唯一 ≠ 稳定 → 只能以 `UNINUMBR` 作追踪键 |
| 都会区字段 | 无 `CBSA_METRO`；`METROBR` 缺失约 3.25% | 同 MSABR 对照覆盖率 98.34%，未覆盖部分进入敏感性讨论 |

**结论**：SOD 作为**权威、全量、结构稳定**的监管数据是可靠的；主要可信度边界不在「数据真假」，
而在**早年（≤2010）主键与坐标的系统性缺失**与**坐标精度随年代大幅提升**这两点。
本项目因此把主结论锚定在 5 km 中等环、并始终给出合并环敏感性。
