① 结论

结论

被同业关闭事件辐射的存活网点，存款增速在事件后逐年加深下行： τ=0 -4.38 pp，τ=4 -10.07 pp； 面板 TWFE 的 post 项 -5.26 pp（p<0.001）。

但聚合层 SLX 的 W_treat 为正，说明存款更可能是在更广地理尺度上 再配置，而不是区域净增 —— 不据此报区域增长红利或 ROI。

守住克制：这是关联证据，不是严格因果。 事件前 τ=−2 已轻微为负（平行趋势近似但非理想），区域共同冲击可能贡献了 post 的下行。

② 机制：距离衰减

机制

核心机制是距离：一个网点被并购关闭后，它的客户会向周边迁移， 而迁移半径是有限的 —— 所以效应应当随距离衰减，而不是均匀铺开。

下面这张图把「强度」定义清楚：每个距离环内同 BKCLASS 的网点数。 注意必须切到密度口径才看得到真实衰减 —— 计数口径会随环面积增大而虚高， 这正是「聚合口径决定结论」的现场演示。

可切换「标准环 / 合并环」×「计数 / 密度」。合并环是坐标精度敏感性口径 （早年坐标多为街道级插值，<1 km 环有系统性失真）。

③ 证据：事件研究

证据

事件研究是本项目最硬的一块证据：它同时给出效应大小与时间形状， 并能检验平行趋势（τ<0 应≈0）。

hover 看每一期的系数、95% CI 与 p 值；基线 τ=−1。误差棒未做 bootstrap， 显著性部分来自大样本。

⑤ 反例与限制

反例与限制

  1. 事件前 τ=−2 轻微为负 → 平行趋势近似但非理想，区域共同冲击可能贡献 post 下行。
  2. 存款转移 ≠ 区域净增 → 不据此报区域增长红利或 ROI。
  3. SAR 在大稀疏 KNN 上 ρ 数值不稳 → 不以 SAR 报溢出量级，仅以 SLX 的 W_treat 作代理。
  4. 坐标精度分年代：2023–2025 EXACT 85.98%，1994–2022 屋顶级仅 16.37% → 主表用 5 km 中等环，<1 km 环只作参考。
  5. 缺失非随机：UNINUMBR 缺失 120,261 行（4.26%）100% 集中在 1994–2010， 2011 年起零缺失 → 早年样本系统性不可追踪，事件研究早期年份代表性弱于近 15 年。
  6. 事件研究未加 bootstrap CI；空间权重仅用 KNN(k=6)，未对比其他权重方案。
止损条件（出现下列用法即停止）
  • 把本结论用于因果断言（如「关闭导致存款流失 X%」）→ 停止，先补 IV/匹配或 Callaway–Sant'Anna 类 staggered 估计。
  • 把点估计换算为区域存款净增 / ROI / 干预阈值 → 停止，成本参数缺失。
  • 用 SAR 的 ρ 或一阶近似报溢出量级 → 停止，数值不稳。
